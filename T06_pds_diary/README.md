# T07 PDS Diary 2 — 인증과 소유권 분리

T06 플랜두씨 다이어리 1을 그대로 이어서, 가입·로그인·로그아웃과 사용자별 자료 분리를 추가한 Cloudflare Workers + D1 프로젝트입니다.

## T06에서 이어진 기능

- PLAN 생성·조회·수정과 수정 전 스냅샷
- 할 일 CRUD·완료/되돌리기·검색·필터·정렬
- DO 실행 기록과 실제 소요시간
- SEE 집계·근거 기록·다음 PLAN 전달
- JSON 전체 내보내기

## T07에서 추가된 기능

- 아이디 가입 / 로그인 / 로그아웃
- PBKDF2-HMAC-SHA-256 비밀번호 저장
  - Web Crypto API 사용
  - 16바이트 랜덤 salt
  - 600,000 iterations
  - 같은 비밀번호도 계정마다 다른 저장값
- 서버 저장형 opaque session
  - 32바이트 랜덤 세션값
  - 브라우저: `HttpOnly`, `SameSite=Strict`, HTTPS에서 `Secure` 쿠키
  - DB: 세션 원문이 아니라 SHA-256 해시만 저장
  - 12시간 만료
  - 로그아웃 및 비밀번호 변경 시 기존 세션 폐기
- 모든 계획/할 일/실행 기록/돌아보기 API에 서버 소유권 검사
  - 다른 계정 자료는 404로 존재 자체를 감춤
  - query/header/body의 임의 `user_id`를 소유권 근거로 사용하지 않음
- T06 기존 자료 승계
  - 첫 가입 계정이 `user_id IS NULL`인 기존 T06 계획을 자동으로 소유
- 잠긴 앱 5일 실제 사용 기록
  - 서버가 `Asia/Seoul` 실제 오늘 날짜를 저장
  - 같은 날짜 중복 거절
  - 5일을 넘겨 저장하지 않음
  - 2일차 뒤·3일차 앞에서만 계획 규칙 1회 변경 가능
  - 합계·평균 자동 계산
- 내 자료 JSON 내보내기
- 비밀번호 변경
- 계정과 연결 자료 전체 삭제
- CSP, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy` 보안 헤더

## 인증 선택

이 프로젝트는 외부 인증 서비스나 별도 비밀번호 라이브러리 대신 **직접 구현 + 표준 Web Crypto API**를 사용합니다. 암호 알고리즘 자체를 새로 만들지 않고 런타임의 PBKDF2 구현을 호출합니다.

선택 이유는 기존 T06의 Workers + D1 구조를 그대로 유지하면서, 과제에서 요구하는 저장된 비밀번호 모습·세션 만료·로그아웃 뒤 거절·자료 소유권 검사를 소스와 D1에서 직접 설명하기 쉽기 때문입니다.

함께 검토한 방법: 외부 인증 서비스(Auth0/Supabase Auth 등). 인증 구현 부담은 줄어들지만 외부 설정과 리디렉션 흐름이 추가되고, 이 과제에서 요구하는 D1 자료 승계와 비밀번호 저장 근거를 한 프로젝트 안에서 설명하기가 더 복잡해 이번에는 선택하지 않았습니다.

## 배포 순서

> 중요: T07-C78 때문에 새 저장소로 옮기지 말고 **최종 T06 commit의 후손 commit**으로 작업해야 합니다.

```bash
# 최종 T06 저장소에서 새 브랜치 생성
git switch -c t07-auth

# 이 폴더의 변경 파일을 같은 프로젝트에 반영한 뒤
git add .
git commit -m "feat: add T07 authentication and ownership isolation"

# 기존 T06 D1 DB에 인증 migration 적용
npm install
npm run db:migrate:remote

# 배포
npm run deploy
```

`wrangler.jsonc`는 T06의 D1 `database_id`를 그대로 사용합니다. 그래야 기존 T06 데이터가 이어집니다.

## 첫 가입 시 T06 자료 승계

migration 뒤 첫 번째로 가입한 계정은 기존 `plans.user_id IS NULL` 계획을 자동으로 가져갑니다. 과제용 단일 사용자 T06 DB를 T07로 승계하기 위한 동작입니다. **원격 DB에서 테스트 계정을 먼저 만들지 말고, 실제로 사용할 내 계정을 첫 계정으로 가입**하세요.

## 5일 사용 기록

1. 로그인 후 `5일 기록`에서 질문·지표·단위·계획 규칙을 고정합니다.
2. 매일 실제 사용 뒤 오늘 값을 1건 기록합니다.
3. 2일차까지 저장되면 3일차 입력 폼이 잠기고 규칙 변경 폼이 나타납니다.
4. 새 규칙과 이유를 저장한 뒤 3~5일차를 같은 지표·단위·계산 규칙으로 기록합니다.
5. 5일이 끝나면 화면 합계·평균을 직접 계산한 값과 대조합니다.
