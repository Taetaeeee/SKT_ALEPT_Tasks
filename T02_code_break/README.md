# CODE BREAK — T02

브라우저에서 실행되는 8비트 터미널 스타일 타이핑 미니게임입니다.
25초 동안 점점 길어지는 보안 암호를 해제해 최대 암호 길이(MAX CODE)를 기록합니다.

## 바로 실행

- 게임 실행: https://taetaeeee.github.io/SKT_ALEPT_Tasks/T02_code_break/
- GitHub: https://github.com/Taetaeeee/SKT_ALEPT_Tasks/tree/main/T02_code_break

## 최종 게임 규칙

- 한 판은 항상 25초 동안 진행합니다.
- NORMAL 시작 길이: 3자리
- NORMAL 목표 길이: 8자리
- EASY 시작 길이: 3자리
- EASY 목표 길이: 7자리
- 정답을 맞히면 다음 암호가 1자리 증가합니다.
- 목표 길이를 달성해도 게임은 끝나지 않고 25초가 끝날 때까지 계속됩니다.
- 오답은 TRACE만 상승하며 시간을 차감하지 않습니다.
- 오답 시 같은 암호에 다시 도전합니다.
- 25초 종료 시 최대 해제 길이(MAX CODE)를 계산합니다.
- MAX CODE가 목표 이상이면 성공, 목표 미만이면 실패입니다.

## 암호 생성과 기록

- 암호는 영문 대문자와 숫자로 생성됩니다.
- 사용 문자: `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`
- `I`, `O`, `0`, `1`은 화면에서 서로 혼동하기 쉬워 제외했습니다.
- 각 자리는 사용 가능한 문자 중 하나를 무작위로 선택합니다.
- 문자와 숫자의 비율을 고정하지 않으므로 문자만 또는 숫자만 포함된 암호가 나올 수도 있습니다.
- 같은 문자가 여러 번 나올 수도 있습니다.
- `MAX CODE`는 한 판에서 성공적으로 해제한 가장 긴 암호 길이입니다.
- `TOTAL CLEARED`는 25초 동안 성공적으로 해제한 암호의 총 개수입니다.

## 점수 / 저장

- NORMAL 모드의 최고 MAX CODE를 `BEST MAX CODE`로 저장합니다.
- EASY MODE 기록은 BEST MAX CODE에 저장하지 않습니다.
- 저장되는 값:
  - BEST MAX CODE
  - 효과음 끄기
  - 화면 효과 줄이기
- `RESET SAVE`로 저장값을 초기화할 수 있습니다.
- 빈 저장값 또는 손상된 저장값은 기본값으로 복구됩니다.

## TRACE

- 오답 누적에 따라 TRACE가 `0% → 25% → 50% → 75% → 90%`로 증가합니다.
- 실패 확정 시 TRACE는 100%가 됩니다.
- 성공 시 결과 TRACE는 `BLOCKED`로 표시됩니다.
- TRACE 단계에 따라 얼굴 표정과 화면 색이 변경됩니다.

## 긴 암호 표시

- 보안 암호 문자열 사이에 실제 공백을 넣지 않습니다.
- 암호는 항상 한 줄로 표시됩니다.
- 길이가 길어질수록 글자 크기와 자간을 자동으로 조절해 코드 패널 폭 안에 맞춥니다.
- 창 크기를 바꾸면 현재 암호의 크기를 다시 계산합니다.

## 화면 레이아웃

데스크톱 게임 화면은 두 열로 구성됩니다.

**왼쪽**
- TRACE 얼굴
- 역추적 상태 문구

**오른쪽**
- 보안 암호
- 입력창
- 정답/오답 피드백

**하단**
- CURRENT / TARGET / CLEARED
- PAUSE / RESTART
- SOUND OFF / REDUCE FX

좁은 화면에서는 자동으로 세로 배치로 전환됩니다.

## EASY MODE 이스터에그

- 메인 메뉴 오른쪽 아래 `[ ? ]` 버튼으로 활성화합니다.
- 목표만 NORMAL 8자리에서 EASY 7자리로 낮아집니다.
- EASY MODE의 BEST MAX 기록은 저장하지 않습니다.
- RESTART 시 EASY MODE를 유지합니다.
- MAIN MENU로 복귀하면 NORMAL MODE로 돌아갑니다.

## 난이도 검증

최종 난이도를 결정하기 위해 시작 길이, 제한시간, 암호 생성 방식, 오답 처리 등 다른 조건은 동일하게 유지하고 `NORMAL_TARGET_LENGTH` 값만 7자리에서 8자리로 변경하여 각각 10회씩 플레이했습니다.

| 구분 | TARGET 7 | TARGET 8 |
| --- | ---: | ---: |
| 플레이 횟수 | 10회 | 10회 |
| MAX CODE 범위 | 7~9자리 | 7~9자리 |
| MAX CODE 중앙값 | 8.5자리 | 8.5자리 |
| 성공 횟수 | 10/10 | 9/10 |

두 조건 모두 MAX CODE 범위는 7~9자리, 중앙값은 8.5자리였습니다.

목표 7자리는 10회 모두 성공했지만 목표 8자리는 9회 성공·1회 실패했습니다. 실제 플레이 기록이 주로 8~9자리에 형성되었고, 대부분 달성 가능하면서도 실수에 따라 실패가 발생하는 난이도로 판단하여 최종 목표 암호 길이를 **8자리**로 선택했습니다.
