# CODE BREAK — T02 v12

브라우저에서 실행되는 8비트 터미널 스타일 타이핑 미니게임입니다.

## 최종 게임 규칙
- 한 판은 항상 25초 동안 진행합니다.
- NORMAL 시작 길이: 3자리
- NORMAL 목표 길이: 8자리
- EASY 시작 길이: 3자리
- EASY 목표 길이: 7자리
- 정답을 맞히면 다음 암호가 1자리 증가합니다.
- 목표 길이를 달성해도 게임은 끝나지 않고 25초가 끝날 때까지 계속됩니다.
- 오답은 TRACE만 상승하며 시간을 차감하지 않습니다.
- 오답 시 같은 암호에 다시 도전합니다.
- 25초 종료 시 최대 해제 길이(MAX CODE)를 계산합니다.
- MAX CODE가 목표 이상이면 성공, 목표 미만이면 실패입니다.

## 점수 / 저장
- 기존 BEST TIME은 제거했습니다.
- NORMAL 모드의 최고 MAX CODE를 `BEST MAX CODE`로 저장합니다.
- EASY MODE 기록은 BEST MAX CODE에 저장하지 않습니다.
- 저장되는 값:
  - BEST MAX CODE
  - 효과음 끄기
  - 화면 효과 줄이기
- RESET SAVE로 저장값을 초기화할 수 있습니다.
- 빈 저장값 또는 손상된 저장값은 기본값으로 복구됩니다.

## TRACE
- 오답 누적에 따라 TRACE 0% → 25% → 50% → 75% → 90%
- 실패 확정 시 TRACE 100%
- 성공 시 결과 TRACE는 BLOCKED
- TRACE 단계에 따라 얼굴 표정과 화면 색이 변경됩니다.

## 긴 암호 표시
- 보안 암호 문자열 사이에 실제 공백을 넣지 않습니다.
- 암호는 항상 한 줄(`white-space: nowrap`)로 표시됩니다.
- 길이가 길어질수록 JavaScript가 글자 크기와 자간을 자동으로 줄여 코드 패널 폭 안에 맞춥니다.
- 창 크기를 바꾸면 현재 암호의 크기를 다시 계산합니다.

## 화면 레이아웃
데스크톱 게임 화면은 두 열로 구성됩니다.

왼쪽:
- TRACE 얼굴
- 역추적 상태 문구

오른쪽:
- 보안 암호
- 입력창
- 정답/오답 피드백

하단:
- CURRENT / TARGET / CLEARED
- PAUSE / RESTART
- SOUND OFF / REDUCE FX

좁은 화면에서는 자동으로 세로 배치로 전환됩니다.

## EASY MODE 이스터에그
- 메인 메뉴 오른쪽 아래 `[ ? ]`로 활성화합니다.
- 목표만 NORMAL 8자리 → EASY 7자리로 낮아집니다.
- EASY BEST MAX 기록은 저장하지 않습니다.
- RESTART 시 EASY 유지
- MAIN MENU 복귀 시 NORMAL 자동 복귀

## T02 난이도 비교
공식 10회 + 10회 비교는 NORMAL 목표 길이만 변경합니다.

- 비교판: NORMAL_TARGET_LENGTH = 7
- 최종판: NORMAL_TARGET_LENGTH = 8

그 외 시작 길이, 25초, 오답 처리, UI/효과/로직은 동일합니다.

## 난이도 검증

최종 난이도를 결정하기 위해 목표 암호 길이만 변경하여 각각 10회씩 플레이했습니다.

| 구분 | TARGET 7 | TARGET 8 |
| --- | ---: | ---: |
| 플레이 횟수 | 10회 | 10회 |
| MAX CODE 범위 | 7~9자리 | 7~9자리 |
| MAX CODE 중앙값 | 8.5자리 | 8.5자리 |
| 성공 횟수 | 10/10 | 9/10 |

두 조건 모두 MAX CODE 범위는 7~9자리, 중앙값은 8.5자리였습니다.
목표 7자리는 10회 모두 성공했지만 목표 8자리는 9회 성공·1회 실패했습니다.

실제 플레이 기록이 주로 8~9자리에 형성되었고,
대부분 달성 가능하면서도 실수에 따라 실패가 발생하는 난이도로 판단하여
최종 목표 암호 길이를 **8자리**로 선택했습니다.

## v12 표시 수정
- 암호 텍스트를 `#security-code-text` 별도 span으로 분리했습니다.
- 자동 크기 조절은 코드 패널 전체 폭이 아니라 실제 암호 문자열의 폭만 측정합니다.
- 3~5자리 64px, 6~7자리 56px, 8~9자리 48px, 10~11자리 40px, 12~14자리 32px을 기본 크기로 사용합니다.
- 실제 폭이 패널을 넘을 때만 자간과 폰트를 추가로 축소합니다.
- 암호는 줄바꿈 없이 한 줄로 표시됩니다.
- 피드백 초기화 시 `\u00a0` 문자열을 출력하지 않고 빈 문자열을 사용합니다.
- 결과 핵심 문구는 PC에서 한 줄로 유지하도록 결과 카드 폭/폰트/자간을 조정했습니다.
- 700px 이하 화면에서는 결과 문구의 자연스러운 줄바꿈을 허용합니다.
