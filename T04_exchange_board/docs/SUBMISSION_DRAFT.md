## 짧은 확인 방법 4줄 — C27

① 위치 — 결과물 주소에서 상단 실제 환율, `외부 실패 합성 재생`, `보존된 실제 일별 기록` 영역을 확인합니다.  
② 행동 — `최신 환율 다시 조회` → 실패 fixture 하나 재생 → `다시 시도 · T04-RECOVER-D2`를 누릅니다.  
③ 통과 모습 — 실제 환율은 값·단위·출처·두 시각·KST가 보이고, 실패 때 마지막 정상값이 `stale`로 유지되며 복구 후 `fresh / none`, 합성 행 2건이 됩니다. 최종 제출 시 실제 기록도 서로 다른 KST 날짜 `2 / 2건`과 어제 대비가 보여야 합니다.  
④ 안 될 때 — 원천 조회 실패 이유와 `stale` 마지막 정상값 또는 합성 `error_code`가 표시되고, `다시 시도` 행동이 보입니다.

## AI와 나의 판단 3줄 — C28

- AI에게 맡긴 일 — 환율 정규화·생활 계산기·공식 fixture 재생·오류/복구 상태·일별 기록 검증·환율 그래프의 코드 구조와 자동 점검 스크립트 작성을 맡겼습니다.
- 직접 판단한 일 — JPY를 대표 기록 신호로 정하고, JPY는 여행비·CNY는 직구·USD는 해외 자격증과 미국주식 환산으로 사용하는 서비스 구성을 직접 선택하고 실제 공개 화면에서 각 단계의 동작을 검사했습니다.
- AI 제안을 따르지 않은 일 — AI가 Graphite Market Desk(A안)를 추천했지만, 실제 환율 정보판에는 더 차분하고 기관 리서치 화면에 가까운 Institutional Navy(B안)가 적합하다고 판단해 B안을 선택했습니다.
