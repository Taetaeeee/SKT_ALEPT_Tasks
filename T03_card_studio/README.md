# T03 | 밈만들기

> 이미지와 문구를 조합해 밈·카드·SNS 게시용 이미지를 만들고 PNG 파일로 저장하는 브라우저 기반 이미지 편집기입니다.

## 바로 사용하기

- **실행:** https://taetaeeee.github.io/SKT_ALEPT_Tasks/T03_card_studio/
- **GitHub:** https://github.com/Taetaeeee/SKT_ALEPT_Tasks/tree/main/T03_card_studio

## 프로젝트 소개

**밈만들기**는 PNG·JPEG 이미지를 불러온 뒤 여러 개의 문구를 추가하고, 위치·크기·색·각도와 이미지 위치를 직접 조정해 원하는 화면비의 결과물을 만드는 도구입니다.

별도 로그인이나 설치 없이 브라우저에서 바로 사용할 수 있으며, 편집 결과는 미리보기와 동일한 PNG 이미지로 내려받을 수 있습니다.

## 주요 기능

### 이미지 편집

- PNG·JPEG 파일 불러오기
- 파일 선택 및 드래그 앤 드롭 업로드
- 지원하지 않는 파일 거부 및 기존 작업 유지
- `사진 위치 조절` 모드에서 이미지 직접 드래그
- 새 이미지 불러오기 및 초기화 시 이미지 위치 중앙 복귀

### 문구 편집

- 여러 개의 문구 추가 및 삭제
- 문구별 개별 선택·편집
- 미리보기에서 문구 직접 드래그 이동
- 글자 크기 조절
- 글자 색 변경
- 글자 각도 슬라이더 조절
- 각도 숫자 직접 입력 (`-180° ~ 180°`)

### 화면비와 내려받기

- `1:1`
- `4:5`
- `9:16`
- 미리보기와 같은 구성으로 PNG 생성
- 내려받기 파일명 자동 순번 적용 (`Image1.png`, `Image2.png`, ...)
- 편집용 선택 테두리는 다운로드 이미지에서 제외

## 템플릿 관리

현재 편집 상태를 사용자 템플릿으로 저장할 수 있습니다.

저장되는 항목:

- 이미지
- 이미지 위치
- 화면비
- 모든 문구의 내용
- 문구 위치
- 글자 크기
- 글자 색
- 글자 각도

지원 기능:

- 새 템플릿 생성
- 저장된 템플릿 불러오기
- 현재 상태로 덮어쓰기
- 템플릿 삭제
- `localStorage`를 이용한 새로고침 후 유지

## JSON 백업·복원

저장된 템플릿 전체를 JSON 파일로 내보내거나 다시 가져올 수 있습니다.

- 정상 JSON: 전체 검증 후 템플릿 복원
- 문법이 손상된 JSON: 가져오기 거부
- 필수 항목이 빠진 JSON: 가져오기 거부
- 오류가 있는 JSON을 선택해도 기존 템플릿은 유지

JSON 기본 구조:

```text
format
version
templates[]
  ├─ id
  ├─ name
  ├─ ratio
  ├─ imageName
  ├─ imageData
  ├─ imageOffsetX
  ├─ imageOffsetY
  ├─ texts[]
  │   ├─ text
  │   ├─ x
  │   ├─ y
  │   ├─ fontSize
  │   ├─ color
  │   └─ rotation
  └─ updatedAt
```

## 사용 방법

1. PNG 또는 JPEG 이미지를 파일 선택 또는 드래그 앤 드롭으로 불러옵니다.
2. 문구를 입력하고 미리보기에서 원하는 위치로 이동합니다.
3. 글자 크기·색·각도를 조절하고 필요한 경우 문구를 추가합니다.
4. `사진 위치 조절`을 켜 이미지 크롭 위치를 조정합니다.
5. `1:1`, `4:5`, `9:16` 중 화면비를 선택합니다.
6. 필요하면 현재 상태를 템플릿으로 저장하거나 JSON으로 백업합니다.
7. `PNG 내려받기`를 눌러 완성 이미지를 저장합니다.

## 검증 내용

최종 제출 전 다음 항목을 직접 확인했습니다.

- PNG·JPEG 정상 불러오기
- 지원하지 않는 파일 거부 및 기존 작업 유지
- 문구 위치·크기·색 변경 즉시 반영
- 다중 문구 입력 및 개별 편집
- 이미지 위치 직접 조절
- `1:1`·`4:5`·`9:16` 미리보기와 다운로드 결과 일치
- 긴 한글·한영 혼합·줄바꿈·이모지·빈 문구·가로/세로/투명 이미지 등을 포함한 극단 입력 검사
- 템플릿 3개 이상 생성·불러오기·수정·삭제 및 새로고침 유지
- 정상 JSON 복원
- 손상 JSON 및 필수 항목 누락 JSON 거부 후 기존 데이터 유지
- 서로 다른 화면비의 완성 이미지 3개 생성 및 정상 열림 확인
- 완성 이미지에 위치정보 메타데이터가 남지 않는지 확인
