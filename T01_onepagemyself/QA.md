# T01 QA 기록 — 최종본

## 현재 파일에서 확인한 항목
- 대상과 목적: `저를 처음 알게 된 사람에게` + 페이지 목적을 한 문장에 명시.
- 공개 범위: 공개 정보 5개, 비공개 정보 5개를 구분해 명시.
- 제목 단계: h1 → h2 → h3 순서 유지.
- 내부 앵커 링크: 선언한 섹션 ID와 일치.
- 공개용 ERD: native `details/summary` 사용.
- 취향 영역: native `button` 사용, `aria-expanded`와 `hidden` 상태를 함께 변경.
- 직접 촬영 사진: button → dialog 확대, Esc 닫기 지원.
- 사진 확대 모션: `prefers-reduced-motion: reduce`에서 비활성화.
- 작성 중 표시 `[내용 필요]`, `[근거 필요]`, `[직접 입력]`: 공개 페이지(index.html)에 없음.

## 최종 배포 후 다시 확인할 항목
- 1366×768 첫 화면에 소개·활동·근거가 함께 보이는지.
- 1920×1080 첫 화면에 소개·활동·근거가 함께 보이는지.
- 두 해상도 가로 넘침 0건인지.
- 모든 외부 근거 링크가 선언한 주소로 열리는지.
- Tab 이동 순서와 Enter/Space 동작이 정상인지.
- 브라우저 콘솔 빨간 오류가 0건인지.
- 공개 URL과 소스 URL이 새 시크릿 창에서 로그인·인증 없이 열리는지.
- 공개 저장소 전체 Git 기록에 비밀번호·토큰·API Key·인증서 원문이 없는지.
