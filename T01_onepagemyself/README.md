# T01 — 나를 소개하는 한 페이지

정적 HTML/CSS/JS로 만든 개인 소개 페이지입니다.

## 구성
- 첫 화면: 대상·목적, 관심 분야, 문제 해결 방식
- 경험 3개: 상황 → 행동 → 결과 → 근거
- 추가 소개: 일하는 기준, 관심 기술, 직접 작성 소개
- 상호작용: `좋아하는 것 보기` 펼치기/접기
- 공개/비공개 범위 표시

## 내가 직접 수정할 곳
`index.html`에서 `[직접 입력]`을 검색하세요.
상세 작성 방법은 `CUSTOMIZE.md`에 정리했습니다.

최종 공개 전에는 `[직접 입력]` 표시를 모두 실제 내용으로 교체하거나 해당 작성 박스를 삭제합니다.

## 로컬 확인
`index.html`을 브라우저에서 열거나 정적 서버로 실행합니다.

예: `python -m http.server 8000`

## 배포 후보
- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

로그인 없이 접근 가능한 공개 URL로 배포해야 합니다.
