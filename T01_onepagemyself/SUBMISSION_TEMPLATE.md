## 3. 짧은 확인 방법 4줄
- 위치: 공개 결과물 주소의 첫 화면에서 시작합니다.
- 행동: ① `대표 경험 보기`를 선택합니다. ② DB 설계 경험의 `공개용 ERD 보기`를 엽니다. ③ ABOUT ME의 `취향을 조금 더 보기`를 마우스 또는 Tab+Enter/Space로 실행합니다.
- 통과 모습: 경험 영역으로 이동하고, ERD가 펼쳐지며, 취향 영역에 카메라와 직접 촬영한 사진이 표시됩니다.
- 안 될 때 모습: 경험 영역으로 이동하지 않거나, ERD·취향 영역이 열리지 않거나, 키보드로 상호작용을 실행할 수 없습니다.

## 4. AI와 나의 판단 3줄
- AI에게 맡긴 일: 과제 통과 기준을 바탕으로 페이지 구조와 HTML/CSS/JavaScript 초안, 접근성 점검, 경험별 문장과 공개 근거 정리를 맡겼습니다.
- 직접 판단한 일: 공개할 경험을 업무 자동화·DB 설계·Hyperledger 트러블슈팅으로 정하고, 03번은 개인정보가 포함될 수 있는 원본 저장소 대신 공개용 Fabric 구성 근거를 사용하기로 직접 판단했습니다.
- AI 제안을 따르지 않은 일: 색상 테마 적용 제안은 현재의 단순한 디자인이 더 적합하다고 판단해 적용하지 않았고, 중복된 상단 취향 버튼과 불필요한 footer도 제거했습니다.

## 5. 실제 결함 3개 이상 수정 전후
1. 수정 전: 페이지 목적은 적혀 있었지만 누구에게 보여주는 페이지인지 대상이 명시되지 않았습니다. / 수정 후: `저를 처음 알게 된 사람에게`라는 대상을 추가해 대상과 목적을 한 문장에 함께 적었습니다.
2. 수정 전: 초기 취향 토글에서 `aria-expanded` 값은 바뀌지만 `hidden` 상태 계산이 반대로 되어 영역이 열리지 않았습니다. / 수정 후: 토글 로직을 수정해 마우스와 키보드에서 정상적으로 열고 닫히도록 했습니다.
3. 수정 전: footer 제거 후 공개할 정보와 공개하지 않을 정보가 한곳에 명시되어 있지 않았습니다. / 수정 후: PUBLIC EVIDENCE 하단에 공개 범위를 추가해 공개 정보 5개와 비공개 정보 5개를 구분했습니다.
4. 수정 전: 첫 화면의 03 경험 미리보기에 `권한`이라고 적혀 상세 트러블슈팅 내용의 `파일 형식`과 표현이 달랐습니다. / 수정 후: `로그·인증서·파일 형식`으로 통일했습니다.
