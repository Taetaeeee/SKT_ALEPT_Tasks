# T03 밈만들기 v11

## 이번 수정: JSON 백업·복원 (C22~C24)
- 저장된 템플릿 목록을 `meme-templates.json`으로 내보내기
- 정상 JSON 파일을 가져오면 전체 템플릿 목록 복원
- JSON 문법이 손상되면 저장 전에 거부하고 기존 템플릿 유지
- 필수 항목이 빠졌거나 형식/범위가 잘못되면 저장 전에 거부하고 기존 템플릿 유지
- 템플릿과 각 문구의 필수 필드를 모두 검증한 뒤에만 localStorage를 교체

### JSON 필수 구조
최상위: `format`, `version`, `templates`

템플릿: `id`, `name`, `ratio`, `imageName`, `imageData`, `texts`, `updatedAt`

문구: `text`, `x`, `y`, `fontSize`, `color`, `rotation`

## C22~C24 확인 방법
1. 템플릿을 저장한 뒤 `JSON 내보내기`로 정상 파일을 만든다.
2. 현재 템플릿 목록을 변경한 뒤 정상 JSON을 가져와 원래 목록이 복원되는지 확인한다.
3. JSON 문법을 일부 깨뜨린 파일을 가져와 오류 메시지와 기존 목록 유지를 확인한다.
4. 템플릿의 필수 항목 하나를 삭제한 JSON을 가져와 오류 메시지와 기존 목록 유지를 확인한다.

## v15 사진 위치 조절
- 편집 도구 상단에서 초기화 버튼 왼쪽에 `사진 위치 조절` 버튼 추가
- 버튼을 켜면 미리보기에서 사진만 드래그 이동
- 버튼을 끄면 기존 문구 드래그 모드로 복귀
- 사진 위치는 템플릿 저장/불러오기 및 JSON 백업/복원에 함께 보존
- 새 이미지를 불러오거나 초기화하면 사진 위치는 중앙으로 복귀
