# T05 고정 검사 — T03 사진 확대·축소

이 문서의 검사 10개는 AI A 작업 시작 전에 고정한 기준이며 AI B에서도 삭제·완화·기대값 변경 없이 그대로 사용한다.

## 공통 사용 상한
- 시간 상한: AI A / AI B 각각 45분
- 요청 상한: AI A / AI B 각각 최대 12회

## 고정 검사 10개

| ID | 입력/행동 | 관찰 가능한 기대값 |
|---|---|---|
| Z01 | 페이지에서 이미지를 업로드한 뒤 이미지 편집 영역을 확인한다. | 사진 크기 조절 UI가 보인다. |
| Z02 | 새 이미지를 불러온다. | 확대율이 100%로 시작한다. |
| Z03 | 확대율을 100%에서 150%로 변경한다. | 미리보기의 사진이 즉시 더 크게 보이고 표시값이 150%다. |
| Z04 | 확대율을 150%에서 50%로 변경한다. | 미리보기의 사진이 즉시 더 작게 보이고 표시값이 50%다. |
| Z05 | 최소값보다 작은 값을 입력하려고 한다. | 확대율이 50% 미만으로 내려가지 않는다. |
| Z06 | 최대값보다 큰 값을 입력하려고 한다. | 확대율이 200%를 넘지 않는다. |
| Z07 | 확대율 150%에서 `사진 위치 조절`을 켜고 사진을 드래그한다. | 확대 상태를 유지하면서 사진 위치가 이동한다. |
| Z08 | 확대율 150%에서 1:1 → 4:5 → 9:16으로 전환한다. | 확대율 150%가 유지되고 각 화면비가 정상 렌더링된다. |
| Z09 | 확대율 150% 상태를 템플릿으로 저장하고 다른 값으로 바꾼 뒤 다시 불러온다. | 저장 당시 확대율 150%가 복원된다. |
| Z10 | 확대율을 포함한 템플릿을 JSON으로 내보내고 다시 가져온다. | 확대율 정보가 JSON에 보존되어 같은 값으로 복원된다. |

## 고정 파라미터
- 기본 확대율: 100%
- 최소 확대율: 50%
- 최대 확대율: 200%
- 단위: %
