밈만들기

이미지와 문구를 조합해 밈·카드·SNS 게시용 이미지를 만들고 내려받는 공개 편집기입니다.

편집 도구

이미지

이미지를 이 영역에 드래그하거나 파일을 선택하세요.

지원 형식: PNG, JPEG · 지원하지 않는 파일은 기존 작업을 유지한 채 거부합니다.

문구

문구 카드 중 하나를 선택하면 아래 설정이 해당 문구에 적용됩니다.

°

미리보기 안의 텍스트를 마우스로 직접 드래그해서 위치를 지정하세요.

화면비
템플릿 관리

현재 이미지·화면비·모든 문구의 위치·크기·색·각도를 함께 저장합니다.

JSON 백업·복원

정상 JSON만 전체 검증 후 복원합니다. 문법이 손상됐거나 필수 항목이 빠진 JSON은 기존 템플릿을 변경하지 않고 거부합니다.
