다음 작업의 도구 선택 기준

빠른 구현보다 기존 코드 보존과 이어받기가 중요한 작업에서는, 인수인계 문서와 실제 소스를 먼저 대조해 작은 변경만 검증할 수 있는 도구를 우선 선택한다.

짧은 확인 방법

① 어디로 가나요 — T05 카드 스튜디오 실행 페이지로 이동합니다.

② 무엇을 하나요 — 이미지를 올리고 150%로 확대 → 템플릿 저장·불러오기 → JSON 내보내기·가져오기를 실행합니다.

③ 무엇이 보이면 통과인가요 — 템플릿과 JSON에서 다시 불러온 뒤에도 확대율이 150%로 복원되면 통과입니다.

④ 안 될 때 무엇이 보이나요 — 확대율이 100%로 초기화되거나 저장한 값과 다르게 복원됩니다.

AI와 나의 판단

AI에게 맡긴 일 — 사진 확대·축소 기능 구현과 확대율을 템플릿·JSON에 보존하는 수정안을 만들고 고정 검사 결과를 정리하게 했습니다.

학생이 직접 판단한 일 — AI가 만든 전체 파일이 원본 구조를 훼손한 경우 사용하지 않고, 실제 원본과 변경 지점을 대조한 뒤 브라우저에서 Z09·Z10을 직접 검증했습니다.

AI 제안을 따르지 않은 일 — 원본보다 크게 축약되어 기존 기능이 사라진 전체 app.js 교체 제안은 사용하지 않았고, 필요한 최소 변경만 반영했습니다.
