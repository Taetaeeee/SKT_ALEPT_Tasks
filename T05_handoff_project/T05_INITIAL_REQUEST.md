# T05 공통 최초 요청

T03 카드 스튜디오에 사진 확대·축소 기능을 추가한다.

조건:
1. 사진 크기는 50%~200% 범위에서 조절하고 기본값은 100%로 한다.
2. 변경은 미리보기에 즉시 반영한다.
3. 확대 상태에서도 기존 사진 위치 조절과 1:1·4:5·9:16 화면비 전환이 정상 동작해야 한다.
4. 최종 완성 상태에서는 템플릿 저장/불러오기와 JSON 내보내기/가져오기에도 확대율이 보존되어야 한다.
5. `T05_TESTS.md`의 Z01~Z10을 삭제·완화·기대값 변경 없이 사용한다.
6. 기존 문구 편집, 템플릿 CRUD, 잘못된 JSON 거부, PNG 다운로드 기능을 깨뜨리지 않는다.
