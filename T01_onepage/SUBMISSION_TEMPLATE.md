# T01 제출문 — 최종 제출 직전 작성

> `[직접 입력]` 부분만 채우면 됩니다. 사이트의 작성용 표시가 모두 제거된 뒤 제출하세요.

## 1. 결과물 주소
- [직접 입력: 로그인 없이 열리는 공개 URL]

## 2. 소스 주소
- [직접 입력: 공개 GitHub 저장소 URL]

## 3. 짧은 확인 방법 4줄
- 위치: 공개 결과물 주소의 첫 화면으로 이동합니다.
- 행동: `경험 근거 보기`를 눌러 경험 영역을 확인한 뒤, `좋아하는 것 보기`를 마우스 또는 Tab+Enter/Space로 실행합니다.
- 통과 모습: 소개와 경험 근거 3개가 보이고, 취향 영역이 펼쳐지며 버튼 문구가 `좋아하는 것 접기`로 바뀝니다.
- 안 될 때 모습: 링크가 이동하지 않거나, 취향 영역이 펼쳐지지 않거나, 키보드로 버튼을 실행할 수 없습니다.

## 4. AI와 나의 판단 3줄
- AI에게 맡긴 일: 과제 통과 기준을 바탕으로 페이지 구조, HTML/CSS/JavaScript 초안, 접근성 점검 항목과 문장 정리를 맡겼습니다.
- 직접 판단한 일: [직접 입력: 어떤 경험을 공개할지, 디자인/표현/공개 범위 중 본인이 결정한 것을 1문장]
- AI 제안을 따르지 않은 일: [직접 입력: 실제로 수정·거절한 제안 1개. 없다면 없었던 이유]

## 5. 실제 결함 3개 수정 전후
1. 수정 전: 대상·목적이 한 문장으로 명확하지 않았습니다. / 수정 후: 대상과 목적을 한 문장으로 추가했습니다.
2. 수정 전: 버튼의 상태값은 바뀌지만 `hidden` 값 계산 오류로 취향 영역이 열리지 않았습니다. / 수정 후: 토글 로직을 수정해 마우스와 키보드에서 정상적으로 열고 닫히게 했습니다.
3. 수정 전: 공개 범위 문구와 실제 공개 내용이 일부 달랐습니다. / 수정 후: `문제 해결 방식`을 공개 범위에 추가해 화면과 점검표를 일치시켰습니다.

### 선택: 본인이 추가로 발견한 결함
- 수정 전: [직접 입력]
- 수정 후: [직접 입력]
