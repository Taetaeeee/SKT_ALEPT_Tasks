# T01 페이지에서 아직 채워야 할 부분

최종 제출 전 `index.html`에서 `[내용 필요]`와 `[근거 필요]`를 검색해 모두 처리합니다.

## [내용 필요]
1. 첫 화면: 나를 기억하게 할 한 문장
2. 자동화 경험: 저장 데이터 형식 / 실제 팀 사용 방식
3. DB 설계 경험: 핵심 테이블 또는 담당 기능의 구체적인 예
4. Hyperledger 경험: 처음 본 오류 메시지 또는 해결 후 확인 테스트
5. 현재 공부 중인 주제 2~3개
6. 요즘 자주 하는 취미·수집·취향 1개
7. 취향과 성격/일하는 방식이 연결되는 부분(선택)

## [근거 필요]
1. 자동화 경험: 실행 화면 / 코드 일부 / README / 결과 파일
2. DB 설계 경험: ERD / 테이블 구조 / 프로젝트 화면 / README
3. Hyperledger 경험: 비밀값 제거한 문제 해결 기록 / 구성도 / README / 로그 캡처
4. 자격 내용을 공개 근거로 쓰고 싶다면 개인정보를 가린 증빙

## 최소 제출 조건
- 과제 기준상 공개 가능한 근거는 최소 1개 이상이면 됩니다.
- 다만 세 경험 중 최소 하나는 실제 링크나 공개 산출물로 연결하는 것을 권장합니다.
- 공개 전 실명·연락처·학번·주소·토큰·API 키·인증서 원문을 다시 검색합니다.
