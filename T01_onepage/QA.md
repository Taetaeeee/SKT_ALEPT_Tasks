# T01 QA 기록 — 확장형 한 페이지 버전

## 기준 화면
- 1366×768: 첫 화면에 소개 문장, 대표 활동 3개, 근거가 있다는 표시가 함께 보임.
- 1920×1080: 동일 핵심 요소가 첫 화면에 보임.
- 두 해상도 모두 document 가로 넘침 0px.

## 구조
- 단일 `index.html`에서 아래로 스크롤하는 한 페이지 구조.
- 제목 단계: h1 → h2 → h3 순으로 구성.
- 첫 화면 이후 경험 상세 → 일하는 방식 → 학습/관심 → 취향 → 공개 근거 순으로 확장.

## 상호작용
- `취향 펼쳐보기`/`취향을 조금 더 보기` 버튼은 native button 요소 사용.
- 마우스 클릭 가능.
- Tab 초점 후 Enter 실행 확인.
- Tab 초점 후 Space 실행 확인.
- aria-expanded와 hidden 상태가 함께 변경됨.
- prefers-reduced-motion 환경에서는 부드러운 스크롤을 끔.

## 브라우저 검사
- 1366×768: console error 0건.
- 1920×1080: console error 0건.

## 작성 중 표시
- `[내용 필요]`: 사용자에게 추가 사실/표현을 받아야 하는 부분.
- `[근거 필요]`: 공개 가능한 산출물/링크가 필요한 부분.
- 최종 제출 전에 두 표시를 검색해 모두 제거해야 함.

## 아직 실제 공개 후 확인할 항목
- GitHub Pages 등 공개 주소를 새 시크릿 창에서 로그인 없이 열 수 있는지.
- 모든 외부 근거 링크가 선언한 주소로 열리는지.
- 공개 파일/Git 기록에 토큰·API 키·인증서 원문 등 비밀값이 없는지.
